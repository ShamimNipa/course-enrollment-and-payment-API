# Course Enrollment & Payment Management REST API

A RESTful backend application for managing users, courses, student enrollments, and payment records.

## Technologies Used
- Node.js
- Express.js
- TypeScript
- PostgreSQL
- JWT Authentication
- bcrypt

## Features
- User registration and login
- Secure password hashing
- JWT-based authentication
- Course management (CRUD)
- Course enrollment management
- Payment record management
- Mock payment processing
- PostgreSQL database integration

## Installation

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd course-enrollment-api
npm install
```

Configure your `.env` file with your PostgreSQL database credentials and JWT secret.

Run the development server:

```bash
npm run dev
```

## API Modules
- Authentication
- Courses
- Enrollments
- Payments

## Payment Note
This project uses a simulated payment workflow for demonstration purposes. It does not process real transactions.
